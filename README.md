# チーム名
VeRyHacker

# プロダクト名
VR手話翻訳

## 概要
MetaQuest3sとUnityのハンドトラッキングを利用して手の形を認識することで、
VRのカメラから読み取った手のデータを文字に変換して手話を翻訳が可能になり、
耳の不自由な方が一般人とコミュニケーションが取れるようになる。

## システム構成

-VRの電源を入れてアプリを起動したら準備完了！

-VRのCameraに自分の手を認識させて手話をしてみよう！

アプリケーション全体の構成が分かる図や説明を記載してください。

## 背景・課題

最近、体が不自由な人間とその周りの人によるヒューマンドラマが描かれたアニメを視聴して、
どうにかしてこのような人々とコミュニケーションをとることができないか考えた。
そのときVRにあるHandTrackingを使えば、耳が不自由な方が手話を知らない人とコミュニケーション
を行うことができるのではないかと思い至った。


## 主な機能

- VRCameraを利用したHandTracking
- HandTrackingによる手の認識を応用した手形の読み取り
- 手形の認識による文字起こし

## 工夫した点・こだわった点

今回のアイデアは一般の方がVRを使いコミュニケーションをとるのではなく、手話を利用する方が手話を知らない人に対してコミュニケーションを図ることができるものとなっており、相手に大きな配慮を求めてしまうことなく会話をすることができるものとなっている。
また、手話はただ単に手の形を変えるだけではなく、手の動きや何種類もの手話によって一つの言葉を伝えるものであるため、できる限り実現ができるように尽力した。


## 使用技術

### XR基盤・規格：
-Meta XR All-in-SDK
-OpenXR Plugin



## 今後の展望

現在導入できている手話の認識機能が少なかったり、認識に問題があるったりとまだまだ実用化にはほど多いため、
-認識できる手話の種類の追加
-手の認識の最適化
-文章による会話ができるようにすることでコミュニケーションのさらなる促進
を目標とします。
